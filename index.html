1日目 🐟 魚の日

主菜 さばの味噌煮

⏱ 仕込み 15分 / 仕上げ 5分　·　🍽 大人2人分（めいちゃんは取り分け）

💡 ポイント: 霜降りをしっかり行うと臭みが消える。調理後に煮汁が薄い場合はふたを開けて少し煮詰めるとコクが出る

🍲 ホットクック使用 / メニュー: さばの味噌煮 / 設定: 予約調理モード。内鍋にさばと調味料を入れて昼セット / 予約調理可

材料
主材料
  • さば（切り身） 2切れ スーパー買出し (土日)
  • しょうが 20g スーパー買出し (土日)
  • 水 100ml スーパー買出し (土日)
調味料
  • 味噌 2大さじ コープ宅配 (水曜締切)
  • みりん 2大さじ スーパー買出し (土日)
  • 砂糖 1大さじ スーパー買出し (土日)
  • 醤油 1大さじ スーパー買出し (土日)
  • 酒 2大さじ スーパー買出し (土日)
作り方
  1. さばに熱湯をかけて霜降りにし、キッチンペーパーで水気を丁寧に拭く
  2. 内鍋に水・酒・みりん・砂糖・醤油・味噌を混ぜ合わせ、しょうが薄切りとさばを皮目を上にして並べる
  3. ホットクック「さばの味噌煮」メニューにセットし、昼に予約→夜に出来上がり
  4. 煮汁をスプーンでかけながら器に盛り付ける

👶 取り分け: 煮あがった身を細かくほぐし、皮と骨を完全に除く。煮汁は塩分が強いので少量のみかける。できる限り柔らかい腹側の身を選ぶ

副菜 かぼちゃの煮物

⏱ 仕込み 10分 / 仕上げ 5分　·　🍽 大人2人分（めいちゃんは取り分け）

💡 ポイント: 皮をところどころ残すと煮崩れしにくく、彩りもきれい。だしパックの代わりに市販だし100mlでも可

🍲 ホットクック使用 / メニュー: かぼちゃの煮物 / 設定: さばの味噌煮と同時に昼予約。別鍋使用 / 予約調理可

材料
主材料
  • かぼちゃ 300g コープ宅配 (水曜締切)
  • だしパック 1個 コープ宅配 (水曜締切)
  • 水 150ml スーパー買出し (土日)
調味料
  • 醤油 1.5大さじ スーパー買出し (土日)
  • みりん 1.5大さじ スーパー買出し (土日)
  • 砂糖 1大さじ スーパー買出し (土日)
作り方
  1. かぼちゃを一口大（約3cm角）に切り、皮をところどころむく
  2. 内鍋にだしパックで作った出汁・調味料・かぼちゃを入れ、ホットクック「かぼちゃの煮物」メニューにセット
  3. さばの味噌煮と同時に昼仕込み可。出来上がったら保温のまま夜まで置く
  4. 盛り付けて完成。煮汁ごとよそう

👶 取り分け: ホットクックで十分柔らかく仕上がるので、めいちゃん分はフォークで粗くつぶすだけでOK。味が濃いと感じたら少量のお湯でのばす

汁物 具だくさん味噌汁

⏱ 仕込み 15分 / 仕上げ 5分　·　🍽 大人2人分（めいちゃんは取り分け）

💡 ポイント: なすは切ってすぐ入れると変色しにくい。味噌は沸騰させると風味が飛ぶので最後に加えること

🍲 ホットクック使用 / メニュー: 勝間流具だくさんみそ汁 / 設定: まとめ炊きで2日分。わかめ・味噌は調理完了後に手動で加える / 予約調理不可

材料
主材料
  • 絹ごし豆腐 150g コープ宅配 (水曜締切)
  • なす 1本 スーパー買出し (土日)
  • 長ねぎ 0.5本 スーパー買出し (土日)
  • わかめ（乾燥） 5g コープ宅配 (水曜締切)
  • だしパック 1個 コープ宅配 (水曜締切)
  • 水 700ml スーパー買出し (土日)
調味料
  • 味噌 3大さじ コープ宅配 (水曜締切)
作り方
  1. なすを半月切り、ねぎを小口切り、豆腐を2cm角に切る
  2. 内鍋に水・だしパック・なす・ねぎ・豆腐を入れ、ホットクック「勝間流具だくさんみそ汁」メニューで調理
  3. 完成後ふたを開け、戻したわかめを加えて味噌を溶き入れる（沸騰させない）
  4. 2日分まとめて作り、翌日は鍋で中火→弱火で温め直す

👶 取り分け: なすと豆腐を小さくちぎって少量取り分ける。味噌汁はお湯を同量加えて薄め、スプーンで少しずつ与える

2日目

主菜 鶏と根菜の筑前煮

⏱ 仕込み 20分 / 仕上げ 10分　·　🍽 大人2人分（めいちゃんは取り分け）

💡 ポイント: こんにゃくは塩もみ→下ゆでで臭みが取れる。根菜は大きめ乱切りにするとホットクックで煮崩れしにくい

🍲 ホットクック使用 / メニュー: 筑前煮 / 設定: 予約調理。さやいんげんは仕上げ後に余熱追加 / 予約調理可

材料
主材料
  • 鶏もも肉 300g コープ宅配 (水曜締切)
  • にんじん 1本 コープ宅配 (水曜締切)
  • れんこん 100g スーパー買出し (土日)
  • ごぼう 0.5本 スーパー買出し (土日)
  • こんにゃく 0.5枚 スーパー買出し (土日)
  • さやいんげん 60g スーパー買出し (土日)
  • 水 100ml スーパー買出し (土日)
調味料
  • 醤油 3大さじ スーパー買出し (土日)
  • みりん 2大さじ スーパー買出し (土日)
  • 砂糖 1大さじ スーパー買出し (土日)
  • 酒 2大さじ スーパー買出し (土日)
作り方
  1. 鶏もも肉を一口大、根菜を乱切り、こんにゃくをちぎって下ゆで（2分）する
  2. 内鍋に鶏肉・根菜・こんにゃく・水・調味料を入れ、ホットクック「筑前煮」メニューにセット。昼予約
  3. 仕上げ直前にさやいんげんを加え、ふたを閉じて3分余熱で火を通す
  4. 全体を混ぜながら器に盛り付ける

👶 取り分け: にんじんと鶏肉（やわらかい部位）を細かく刻んで少量取り分ける。れんこん・ごぼうは硬いので薄切りにするか省く。煮汁が濃ければお湯で薄める

副菜 ほうれん草の胡麻和え

⏱ 仕込み 10分 / 仕上げ 5分　·　🍽 大人2人分（めいちゃんは取り分け）

💡 ポイント: 茎から先にゆでて葉は短時間で引き上げると鮮やかな緑色をキープできる。水気は手でしっかり絞ること

コンロ・手作業

材料
主材料
  • ほうれん草 1束 コープ宅配 (水曜締切)
  • 白すりごま 2大さじ スーパー買出し (土日)
調味料
  • 醤油 1大さじ スーパー買出し (土日)
  • 砂糖 0.5大さじ スーパー買出し (土日)
  • みりん 0.5大さじ スーパー買出し (土日)
作り方
  1. 湯を沸かし、茎を先に30秒、葉を15秒ゆでて冷水にとる
  2. 水気をしっかり絞り3cm長さに切る
  3. ごま・醤油・砂糖・みりんを混ぜ合わせ、ほうれん草と和える

👶 取り分け: 細かく刻んで少量取り分け、醤油を控えめにしたタレで薄く和える。ごまは誤嚥防止のため少量にとどめ、よくすり混ぜる

3日目

主菜 豚肉と白菜のミルフィーユ蒸し

⏱ 仕込み 15分 / 仕上げ 10分　·　🍽 大人2人分（めいちゃんは取り分け）

💡 ポイント: 豚バラと白菜を交互にしっかり重ねるほどジューシーに仕上がる。蒸しすぎると白菜が水っぽくなるので15分を超えないよう注意

🍲 ホットクック使用 / メニュー: 手動調理 > 蒸す > 15分 / 設定: 手動蒸しモード。内鍋底に水50mlを先に入れてから食材を並べる / 予約調理不可

材料
主材料
  • 豚バラ薄切り肉 200g コープ宅配 (水曜締切)
  • 白菜 300g コープ宅配 (水曜締切)
  • 水 50ml スーパー買出し (土日)
調味料
  • ポン酢 3大さじ スーパー買出し (土日)
  • ごま油 1大さじ スーパー買出し (土日)
  • 塩 0.5小さじ スーパー買出し (土日)
作り方
  1. 白菜の葉1枚・豚バラ1枚を交互に4〜5層重ね、5cm長さに切る
  2. 内鍋に水50mlを入れ、切り口を上にして隙間なく並べ、塩を全体に振る
  3. ホットクック「手動調理 > 蒸す > 15分」でセット
  4. 仕上げにポン酢とごま油を回しかけて盛り付ける

👶 取り分け: 蒸しあがった白菜と豚肉を細かく刻んで取り分ける。ポン酢は塩分・酸味が強いため使わず、蒸し汁少々のみ。そのままか少量のお湯であえて与える

副菜 ひじきの煮物

⏱ 仕込み 25分 / 仕上げ 5分　·　🍽 大人2人分（めいちゃんは取り分け）

💡 ポイント: 油揚げは熱湯で油抜きすると味が染み込みやすくなる。ひじきは戻しすぎず20分を目安にすると食感が残る

🍲 ホットクック使用 / メニュー: ひじきの煮物 / 設定: 予約調理可。ひじきの戻し（20分）は昼仕込み前に開始 / 予約調理可

材料
主材料
  • 乾燥ひじき 20g コープ宅配 (水曜締切)
  • にんじん 0.5本 コープ宅配 (水曜締切)
  • 油揚げ 1枚 コープ宅配 (水曜締切)
  • 大豆水煮 50g コープ宅配 (水曜締切)
  • 水 150ml スーパー買出し (土日)
調味料
  • ごま油 1大さじ スーパー買出し (土日)
  • 醤油 2大さじ スーパー買出し (土日)
  • みりん 2大さじ スーパー買出し (土日)
  • 砂糖 1大さじ スーパー買出し (土日)
作り方
  1. 乾燥ひじきを水で20分戻し、水気を切る
  2. にんじんを細切り、油揚げを熱湯で油抜きして短冊切りにする
  3. 内鍋にごま油・ひじき・にんじん・油揚げ・大豆・水・調味料を入れ、ホットクック「ひじきの煮物」メニューにセット
  4. 出来上がったら全体を混ぜ、器に盛り付ける

👶 取り分け: ひじきを細かく刻み、にんじん・大豆とともに少量取り分ける。大豆はスプーンで潰してから与える。醤油の味が濃ければお湯少々でのばす

汁物 豆腐とねぎのすまし汁

⏱ 仕込み 10分 / 仕上げ 10分　·　🍽 大人2人分（めいちゃんは取り分け）

💡 ポイント: 沸騰させ続けると汁が濁るので弱火で仕上げること。豆腐は煮崩れしないよう最後に加える

コンロ・手作業

材料
主材料
  • 絹ごし豆腐 150g コープ宅配 (水曜締切)
  • 長ねぎ 0.5本 スーパー買出し (土日)
  • だしパック 1個 コープ宅配 (水曜締切)
  • 水 500ml スーパー買出し (土日)
調味料
  • 醤油 1小さじ スーパー買出し (土日)
  • 塩 0.5小さじ スーパー買出し (土日)
作り方
  1. だしパックと水を鍋に入れ、中火で5分煮てだしをとる
  2. ねぎを小口切り、豆腐を2cm角に切り鍋に加える
  3. 弱中火で温め、醤油・塩で味を整え椀に盛る

👶 取り分け: 豆腐をスプーンでつぶしてスープと一緒に少量取り分ける。ねぎは細かく刻む。すまし汁はそのまま薄めずに与えてもよいが、塩分が気になる場合はお湯少々で調整する
